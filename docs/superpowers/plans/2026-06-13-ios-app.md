# Salsa Event Tracker — iOS App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native SwiftUI iOS app that replicates all features of the existing web app (event calendar, festival list, trips, reviews, auth) against the same Supabase backend, while the web app (`web/`) remains completely untouched.

**Architecture:** All iOS code lives in a new `ios/` directory at the repo root. A shared `SupabaseService` handles all REST calls using `URLSession` (no third-party SDK needed — the existing API is simple REST+JWT). `AppModel` is a `@MainActor @Observable` class that owns all state, injected via SwiftUI environment. Navigation uses a tab bar with five tabs mirroring the web's five views.

**Tech Stack:** SwiftUI, iOS 17+, `@Observable` (Observation framework), `URLSession` for Supabase REST, `KeychainAccess` (SPM) for secure token storage, no SwiftData (all data fetched fresh from Supabase on launch, same as web).

## Engineering Standards

> **Read before making any change to `ios/`.** These rules apply permanently — to the initial build and to all future features.
>
> The living version of this document lives at `ios/docs/engineering-standards.md`. The content below is the seed; update that file if rules evolve.

### File size limits

| Layer | Soft limit | Hard limit | Action |
|---|---|---|---|
| View (root) | 250 lines | 400 lines | Extract sub-views or split by concern |
| Service | 300 lines | 500 lines | Split by sub-domain (auth vs. data) |
| AppModel | 300 lines | 500 lines | Extract extension files (see below) |
| Model | 100 lines | 200 lines | Split if domains are distinct |
| Utility | 80 lines | 150 lines | Split if unrelated helpers accumulate |

The soft limit is a prompt to ask "should I split this?" The hard limit requires action before merging.

### AppModel

`AppModel.swift` starts as a single file. When it exceeds the hard limit, extract extensions:

| Extension file | Domain |
|---|---|
| `AppModel+Types.swift` | All enums, structs, and type aliases (`Tab`, `EventSortOption`, `AppError`) |
| `AppModel+Auth.swift` | Auth callbacks, sign-in/sign-out, token-expiry recovery |
| `AppModel+Data.swift` | Public and private data loading from Supabase |
| `AppModel+Filters.swift` | Derived computed properties, sort, filter |

Rules:
- Stored properties and `init` stay in `AppModel.swift`.
- `AppModel+Types.swift` is extracted from day one — do not define `enum` or support types inline in `AppModel.swift`.
- Never put `UserDefaults`, `Keychain`, or networking logic directly in `AppModel.swift`; delegate to services.

### Service layer

- **Every service used by `AppModel` must have a protocol counterpart** (`SupabaseServiceProtocol`, `AuthServiceProtocol`). The concrete type adopts it. This is the only way to mock services in unit tests.
- **Services must not import `SwiftUI`.** Only `Foundation`, `KeychainAccess`, `URLSession`. Services operate on model types — they never touch `View`, `@State`, or `@Environment`.
- **`SupabaseConfig.swift` is the only file that contains the Supabase URL and anon key.** No other file references them directly.
- **Auth tokens live only in the Keychain** (via `KeychainAccess`). Never in `UserDefaults`, logs, or printed strings.
- **Never log auth tokens, user IDs, or private row content** at any log level, even in `#if DEBUG`.

### Model layer

- Models are pure `Codable` + `Identifiable` structs. No `@Observable`, no `@Published`, no business logic.
- `ReviewCategory` enum belongs in `Review.swift` (tightly coupled). All other support enums belong in `AppModel+Types.swift`.
- Do not add computed properties that call services or format for display. Keep models as plain data carriers.

### Testing

- **Utility functions with branching logic must be unit tested.** `SchengenCalculator.daysUsed`, `TextUtils.matches`, `ReviewScoring.totalScore`, and `DateUtils.calendarGrid` all have edge cases that regression-prone.
- **`AppModel` loading logic must be tested against mock services.** Use `SupabaseServiceProtocol` mocks that return fixture data without hitting the network.
- **Tests must not hit the real Supabase project.** All network calls must be injected via protocol.
- Test file: `SalsaEventTrackerTests/AppModelTests.swift`. Mirror the domain: auth tests, data loading tests, Schengen tests, filter tests.

## Security

### Threat Model: What an Attacker Can Do With the Extracted App Binary

Anyone who decompiles the app binary can extract the Supabase project URL and anon key using standard reverse-engineering tools (`strings`, `otool`, Hopper). With those two values they can query your Supabase project directly from `curl`, Postman, or a script — completely bypassing the iOS app. The threat scenarios are:

| Threat | Blocked by RLS alone? | Notes |
|--------|-----------------------|-------|
| Read other users' private trips/reviews | Yes — if RLS is correct | Must be verified; see Layer 1 |
| Read all public event data (scraping) | **No** | Public data is public by design |
| Brute-force the login endpoint | **No** | Supabase auth endpoint is exposed |
| Enumerate valid email addresses via auth errors | **No** | Supabase returns distinct errors for "no account" vs "wrong password" by default |
| Discover the database schema via PostgREST | **No** | `/rest/v1/` returns table/column metadata to anon role by default |
| Create unlimited fake accounts | **No** — unless signups are disabled | Fake accounts can then probe auth-gated endpoints |
| Write/delete data as anon | Yes — if anon role has no write grants | Must be verified |

**RLS alone is not sufficient.** The defenses below are layered — implement them all.

---

### Layer 1: Mandatory Supabase Dashboard Settings (Do Before First Run)

These are one-time configuration changes in the Supabase dashboard. None require code changes.

#### 1a. Disable Public Signups

This is the single most important setting for a personal app. If no one can create accounts, the auth endpoint becomes useless to an attacker.

Supabase Dashboard → **Authentication → Providers → Email** → toggle **"Enable Email Signups"** OFF.

After this, `POST /auth/v1/signup` returns an error for everyone. Only accounts you create manually in the dashboard can log in.

#### 1b. Disable Schema Introspection

By default, PostgREST exposes the full database schema at `/rest/v1/`. Disable it:

Supabase Dashboard → **Settings → API** → toggle **"Enable Schema Introspection"** OFF (also labeled "Expose schema" in some versions).

After this, `GET /rest/v1/` returns an empty response instead of your table/column/type metadata.

#### 1c. Lock Down the Anon Role to Read-Only on Public Tables Only

In the Supabase SQL editor, confirm or run:

```sql
-- Confirm anon has NO privileges on private tables
REVOKE ALL ON personal_trips FROM anon;
REVOKE ALL ON personal_trip_places FROM anon;
REVOKE ALL ON personal_pto_days FROM anon;
REVOKE ALL ON reviews FROM anon;

-- Confirm anon has only SELECT on public tables
GRANT SELECT ON events TO anon;
GRANT SELECT ON event_editions TO anon;
GRANT SELECT ON dance_styles TO anon;
GRANT SELECT ON schengen_countries TO anon;
```

This means even if RLS is accidentally disabled on a private table, the anon role still cannot read it — there are two independent gates.

#### 1d. Verify RLS Is Enforced on All Private Tables

Supabase Dashboard → **Table Editor** → for each private table, confirm "Row Level Security" is ON.

Policies required:

| Table | Policy condition |
|-------|-----------------|
| `personal_trips` | `owner_id = auth.uid()` for SELECT/INSERT/UPDATE/DELETE |
| `personal_trip_places` | `owner_id = auth.uid()` |
| `personal_pto_days` | `owner_id = auth.uid()` |
| `reviews` | `user_id = auth.uid()` |

**Smoke test each table** from the command line:

```bash
# Should return [] — no rows visible to anon
curl "https://YOUR_PROJECT.supabase.co/rest/v1/personal_trips?select=*" \
  -H "apikey: YOUR_ANON_KEY"

curl "https://YOUR_PROJECT.supabase.co/rest/v1/reviews?select=*" \
  -H "apikey: YOUR_ANON_KEY"
```

If either returns rows, stop — RLS is misconfigured.

#### 1e. Enable Auth Rate Limiting

Supabase Dashboard → **Authentication → Rate Limits**. Set:
- **Email sign-ins per hour**: 5 (prevents brute-force login attacks)
- **Token refresh per hour**: 30
- **Sign-ups per hour**: 0 (or leave at default if signups are disabled — both protect you)

#### 1f. Opaque Auth Error Messages

Supabase Dashboard → **Authentication → Settings** → enable **"Obscure email-based errors"** (may be labeled differently depending on dashboard version). This makes "no account with this email" and "wrong password" return the same generic error, preventing email enumeration.

### Layer 2: Keys in the App Binary

Supabase issues two keys:

| Key | Where it lives | What it can do |
|-----|---------------|----------------|
| **Anon key** | App binary, `SupabaseConfig.swift`, `web/supabase-config.js` | Identifies project; subject to RLS and anon role grants |
| **Service role key** | `scripts/` only, CI env vars | Bypasses RLS entirely — never in the app |

The anon key **will** be extracted from the binary by anyone who tries. After completing Layer 1, the damage an attacker can do with it is:
- Read public event data (intended and acceptable)
- Attempt login (rate-limited, and signups are disabled so they need a real credential)
- Nothing else — private tables are gated by both RLS and anon role grants

Do not put `SupabaseConfig.swift` in `.gitignore`. The anon key is already public in `web/supabase-config.js` in this same repo. Hiding it in the iOS code but not the web code is security theater.

The service role key must never appear anywhere in the `ios/` directory. If a code reviewer ever sees `service_role` or a second long JWT in iOS code, treat it as a critical security incident.

---

### Layer 3: Optional Hardening — Edge Function Proxy

If you need to prevent direct PostgREST access entirely (e.g., you want to add IP blocking, custom rate limiting, or audit logging beyond what Supabase offers), replace direct PostgREST calls with Supabase Edge Functions.

**How it works:**
- The iOS app calls `https://YOUR_PROJECT.supabase.co/functions/v1/api` with a custom `X-App-Secret` header containing a HMAC signature
- The Edge Function validates the signature, then queries the database using the **service role key** (stored server-side inside the function, never in the app binary)
- PostgREST is never called directly from the app
- The anon key is no longer needed in the app at all

**What this adds:**
- The raw Supabase URL + a leaked anon key becomes useless — PostgREST still exists but the anon role has no grants
- Custom rate limiting and audit logging at the Edge Function layer
- Ability to rotate the app-side secret without a new app binary (via Supabase secrets)
- IP-based blocking or geo-fencing in the Edge Function

**What this does NOT add:**
- The `X-App-Secret` in the binary can still be extracted. An attacker can still call the Edge Function. The advantage is the Edge Function gives you a programmable gate to add additional validation (device attestation, request fingerprinting, etc.).

**Implementation sketch** (out of scope for this plan — add as a follow-up task if needed):

```typescript
// supabase/functions/api/index.ts
import { serve } from "https://deno.land/std/http/server.ts"
import { createClient } from "https://esm.sh/@supabase/supabase-js"

serve(async (req) => {
  const appSecret = req.headers.get("X-App-Secret")
  if (appSecret !== Deno.env.get("APP_SECRET")) {
    return new Response("Unauthorized", { status: 401 })
  }
  // Use service role client — never exposed to app binary
  const supabase = createClient(
    Deno.env.get("SUPABASE_URL")!,
    Deno.env.get("SUPABASE_SERVICE_ROLE_KEY")!
  )
  // Route to appropriate query based on req.url / req.method
  // ...
})
```

The iOS app then sends `X-App-Secret: <value-from-SupabaseConfig>` on every request instead of an anon key.

**Verdict for this app:** Layers 1 and 2 are sufficient for a personal single-user app. Add Layer 3 only if the app is distributed to others or if audit logging becomes a requirement.

### Auth Token Storage

- Access tokens and refresh tokens are stored in the **iOS Keychain** via `KeychainAccess`, not `UserDefaults`. Keychain items are encrypted by the OS at rest and are isolated per app bundle ID.
- Supabase access tokens expire after **1 hour** by default. `AuthService.restoreSession()` clears expired sessions on launch.
- **Token refresh is not implemented in this plan.** After 1 hour of use, API calls will return 401. Handle this in `SupabaseService.checkStatus`:

```swift
// Add to SupabaseService:
enum AuthError: Error { case tokenExpired }

// In checkStatus:
if (response as? HTTPURLResponse)?.statusCode == 401 {
    throw AuthError.tokenExpired
}
```

In `AppModel`, catch `AuthError.tokenExpired`, call `signOut()`, and the login sheet reappears. If seamless background refresh is needed, call `POST /auth/v1/token?grant_type=refresh_token` with the stored refresh token — but this adds significant complexity and is out of scope here.

### No Sensitive Data in Logs

- Never `print` or `os_log` auth tokens, refresh tokens, user IDs, or private row contents at any log level.
- `SupabaseService.checkStatus` surfaces raw Supabase error bodies which may contain row data or email addresses. Wrap all request/response logging in `#if DEBUG`.
- In production builds, log only HTTP status codes, never request or response bodies for authenticated endpoints.

### Data in Transit

`URLSession` enforces TLS 1.2+ via App Transport Security (ATS) by default. Supabase uses HTTPS exclusively. **Do not add any `NSAppTransportSecurity` exceptions to `Info.plist`** — if the build requires one, that is a misconfiguration, not a valid workaround.

### Data at Rest

- No private data (trips, reviews) is cached to disk. All data loads fresh from Supabase on launch, matching the web app's behavior.
- The only persisted sensitive data is auth tokens in the Keychain.
- Do not write trips, reviews, or user IDs to `UserDefaults`, `NSCache`, temp files, or any on-disk location.

### What Cannot Be Fully Prevented

Even with all layers implemented, the following remain true:

- **Public event data can always be scraped.** Anyone with the Supabase URL (or even just by watching network traffic from the app) can read public festival data. This is inherent to the design — public data is public.
- **A determined attacker can call the Edge Function** if they extract the `X-App-Secret`. Layer 3 raises the bar, it does not create an impenetrable wall.
- **Credentials on a jailbroken device** — Keychain items can be extracted on jailbroken hardware. This is an accepted risk for personal-use apps at this sensitivity level.

```swift
import Foundation

enum DateUtils {
    private static let isoFormatter: DateFormatter = {
        let f = DateFormatter()
        f.dateFormat = "yyyy-MM-dd"
        f.locale = Locale(identifier: "en_US_POSIX")
        f.timeZone = TimeZone(secondsFromGMT: 0)
        return f
    }()

    static func todayString() -> String {
        isoFormatter.string(from: Date())
    }

    static func date(from string: String) -> Date? {
        isoFormatter.date(from: string)
    }

    static func string(from date: Date) -> String {
        isoFormatter.string(from: date)
    }

    static func displayDate(_ isoString: String) -> String {
        guard let d = date(from: isoString) else { return isoString }
        let f = DateFormatter()
        f.dateStyle = .medium
        return f.string(from: d)
    }

    static func displayDateRange(start: String, end: String) -> String {
        guard let s = date(from: start), let e = date(from: end) else { return "\(start) – \(end)" }
        let f = DateFormatter()
        f.dateStyle = .medium
        if Calendar.current.isDate(s, equalTo: e, toGranularity: .month) {
            let sf = DateFormatter(); sf.dateFormat = "MMM d"
            let ef = DateFormatter(); ef.dateFormat = "d, yyyy"
            return "\(sf.string(from: s))–\(ef.string(from: e))"
        }
        return "\(f.string(from: s)) – \(f.string(from: e))"
    }

    static func monthLabel(_ isoYearMonth: String) -> String {
        // isoYearMonth: "2026-06"
        guard isoYearMonth.count == 7 else { return isoYearMonth }
        let padded = isoYearMonth + "-01"
        guard let d = date(from: padded) else { return isoYearMonth }
        let f = DateFormatter(); f.dateFormat = "MMMM yyyy"
        return f.string(from: d)
    }

    // Returns all calendar days for the month containing `yearMonth` ("YYYY-MM")
    // Padded with nil for days before Monday-aligned start
    static func calendarGrid(for yearMonth: String) -> [Date?] {
        guard let firstDay = date(from: yearMonth + "-01") else { return [] }
        var cal = Calendar.current
        cal.firstWeekday = 2 // Monday
        let range = cal.range(of: .day, in: .month, for: firstDay)!
        let firstWeekday = cal.component(.weekday, from: firstDay)
        let offset = (firstWeekday - cal.firstWeekday + 7) % 7
        var days: [Date?] = Array(repeating: nil, count: offset)
        for day in 1...range.count {
            var comps = cal.dateComponents([.year, .month], from: firstDay)
            comps.day = day
            days.append(cal.date(from: comps))
        }
        return days
    }
```

```swift
// ios/SalsaEventTracker/Utils/SchengenCalculator.swift
import Foundation

enum SchengenCalculator {
    // Given a set of Schengen-area stays (as date-range pairs), calculate
    // how many days have been spent in the Schengen area in the 180-day
    // rolling window ending on `checkDate`.
    static func daysUsed(
        stays: [(start: String, end: String)],
        checkDate: String,
        schengenCountries: Set<String>
    ) -> Int {
        guard let check = DateUtils.date(from: checkDate) else { return 0 }
        guard let windowStart = Calendar.current.date(byAdding: .day, value: -179, to: check) else { return 0 }

        var total = 0
        for stay in stays {
            guard let s = DateUtils.date(from: stay.start),
                  let e = DateUtils.date(from: stay.end) else { continue }
            let clampedStart = max(s, windowStart)
            let clampedEnd = min(e, check)
            if clampedStart <= clampedEnd {
                total += Calendar.current.dateComponents([.day], from: clampedStart, to: clampedEnd).day! + 1
            }
        }
        return min(total, 90)
    }

    // Returns Schengen-impacting stays from a list of trip places
    static func schengenStays(from places: [TripPlace], schengenCountries: Set<String>) -> [(start: String, end: String)] {
        places
            .filter { schengenCountries.contains($0.country) }
            .map { (start: $0.startDate, end: $0.endDate) }
    }
}
```

```swift
// ios/SalsaEventTracker/Services/SupabaseService.swift
import Foundation

actor SupabaseService {
    private let baseURL: URL
    private let anonKey: String
    private let session: URLSession

    init(baseURL: URL = SupabaseConfig.url, anonKey: String = SupabaseConfig.anonKey) {
        self.baseURL = baseURL
        self.anonKey = anonKey
        self.session = URLSession.shared
    }

    // MARK: - Public

    func fetchEvents() async throws -> [Event] {
        let url = baseURL.appending(path: "/rest/v1/events")
            .appending(queryItems: [
                URLQueryItem(name: "select", value: "*,event_editions(*)"),
                URLQueryItem(name: "visibility", value: "eq.public")
            ])
        return try await get(url: url, token: nil)
    }

    func fetchDanceStyles() async throws -> [DanceStyle] {
        let url = baseURL.appending(path: "/rest/v1/dance_styles")
            .appending(queryItems: [URLQueryItem(name: "select", value: "id,name,slug,is_active,sort_order")])
        return try await get(url: url, token: nil)
    }

    func fetchSchengenCountries() async throws -> [SchengenCountryRow] {
        let url = baseURL.appending(path: "/rest/v1/schengen_countries")
            .appending(queryItems: [URLQueryItem(name: "select", value: "country_name,is_schengen")])
        return try await get(url: url, token: nil)
    }

    // MARK: - Authenticated

    func fetchTrips(token: String) async throws -> [Trip] {
        let url = baseURL.appending(path: "/rest/v1/personal_trips")
            .appending(queryItems: [
                URLQueryItem(name: "select", value: "*,personal_trip_places(*),personal_pto_days(*)")
            ])
        return try await get(url: url, token: token)
    }

    func fetchReviews(token: String) async throws -> [Review] {
        let url = baseURL.appending(path: "/rest/v1/reviews")
            .appending(queryItems: [URLQueryItem(name: "select", value: "*")])
        return try await get(url: url, token: token)
    }

    func createTrip(_ body: [String: Any], token: String) async throws -> Trip {
        let url = baseURL.appending(path: "/rest/v1/personal_trips")
        return try await post(url: url, body: body, token: token)
    }

    func updateTrip(id: String, body: [String: Any], token: String) async throws {
        let url = baseURL.appending(path: "/rest/v1/personal_trips")
            .appending(queryItems: [URLQueryItem(name: "id", value: "eq.\(id)")])
        try await patch(url: url, body: body, token: token)
    }

    func deleteTrip(id: String, token: String) async throws {
        let url = baseURL.appending(path: "/rest/v1/personal_trips")
            .appending(queryItems: [URLQueryItem(name: "id", value: "eq.\(id)")])
        try await delete(url: url, token: token)
    }

    func replaceTripPlaces(tripId: String, places: [[String: Any]], token: String) async throws {
        // Delete existing then bulk-insert
        let delURL = baseURL.appending(path: "/rest/v1/personal_trip_places")

        try await delete(url: delURL, token: token)
        if !places.isEmpty {
            let insURL = baseURL.appending(path: "/rest/v1/personal_trip_places")
            try await postMany(url: insURL, body: places, token: token)
        }
    }

    func replacePTODays(tripId: String, ptoDays: [[String: Any]], token: String) async throws {
        let delURL = baseURL.appending(path: "/rest/v1/personal_pto_days")
            .appending(queryItems: [URLQueryItem(name: "trip_id", value: "eq.\(tripId)")])
        try await delete(url: delURL, token: token)
        if !ptoDays.isEmpty {
            let insURL = baseURL.appending(path: "/rest/v1/personal_pto_days")
            try await postMany(url: insURL, body: ptoDays, token: token)
        }
    }

    func createReview(_ body: [String: Any], token: String) async throws -> Review {
        let url = baseURL.appending(path: "/rest/v1/reviews")
        return try await post(url: url, body: body, token: token)
    }

    func updateReview(id: String, body: [String: Any], token: String) async throws {
        let url = baseURL.appending(path: "/rest/v1/reviews")
            .appending(queryItems: [URLQueryItem(name: "id", value: "eq.\(id)")])
        try await patch(url: url, body: body, token: token)
    }

    func deleteReview(id: String, token: String) async throws {
        let url = baseURL.appending(path: "/rest/v1/reviews")
            .appending(queryItems: [URLQueryItem(name: "id", value: "eq.\(id)")])
        try await delete(url: url, token: token)
    }

    // MARK: - Private helpers

    private func headers(token: String?) -> [String: String] {
        var h = ["apikey": anonKey, "Content-Type": "application/json"]
        if let t = token { h["Authorization"] = "Bearer \(t)" }
        return h
    }

    private func get<T: Decodable>(url: URL, token: String?) async throws -> T {
        var req = URLRequest(url: url)
        headers(token: token).forEach { req.setValue($1, forHTTPHeaderField: $0) }
        let (data, resp) = try await session.data(for: req)
        try checkStatus(resp, data: data)
        return try JSONDecoder().decode(T.self, from: data)
    }

    private func post<T: Decodable>(url: URL, body: [String: Any], token: String) async throws -> T {
        var req = URLRequest(url: url)
        req.httpMethod = "POST"
        var h = headers(token: token); h["Prefer"] = "return=representation"
        h.forEach { req.setValue($1, forHTTPHeaderField: $0) }
        req.httpBody = try JSONSerialization.data(withJSONObject: body)
        let (data, resp) = try await session.data(for: req)
        try checkStatus(resp, data: data)
        // Supabase returns an array; take first
        let arr = try JSONDecoder().decode([T].self, from: data)
        guard let first = arr.first else { throw URLError(.badServerResponse) }
        return first
    }

    private func postMany(url: URL, body: [[String: Any]], token: String) async throws {
        var req = URLRequest(url: url)
        req.httpMethod = "POST"
        headers(token: token).forEach { req.setValue($1, forHTTPHeaderField: $0) }
        req.httpBody = try JSONSerialization.data(withJSONObject: body)
        let (data, resp) = try await session.data(for: req)
        try checkStatus(resp, data: data)
    }

    private func patch(url: URL, body: [String: Any], token: String) async throws {
        var req = URLRequest(url: url)
        req.httpMethod = "PATCH"
        headers(token: token).forEach { req.setValue($1, forHTTPHeaderField: $0) }
        req.httpBody = try JSONSerialization.data(withJSONObject: body)
        let (data, resp) = try await session.data(for: req)
        try checkStatus(resp, data: data)
    }

    private func delete(url: URL, token: String) async throws {
        var req = URLRequest(url: url)
        req.httpMethod = "DELETE"
        headers(token: token).forEach { req.setValue($1, forHTTPHeaderField: $0) }
        let (_, resp) = try await session.data(for: req)
        try checkStatus(resp, data: nil)
    }

    // MARK: - Errors
    enum AuthError: Error { case tokenExpired }

    private func checkStatus(_ response: URLResponse, data: Data?) throws {
        guard let http = response as? HTTPURLResponse,
              (200...299).contains(http.statusCode) else {
            if (response as? HTTPURLResponse)?.statusCode == 401 {
                throw AuthError.tokenExpired
            }
            let msg = data.flatMap { String(data: $0, encoding: .utf8) } ?? "Unknown error"
            throw NSError(domain: "SupabaseService", code: (response as? HTTPURLResponse)?.statusCode ?? 0,
                          userInfo: [NSLocalizedDescriptionKey: msg])
        }
    }
}
```

```swift
// ios/SalsaEventTracker/Services/AuthService.swift
import Foundation
import KeychainAccess

struct AuthSession {
    let accessToken: String
    let refreshToken: String
    let expiresAt: Date
    let userId: String
    let email: String
}

@MainActor
@Observable
final class AuthService {
    private(set) var session: AuthSession?

    private let keychain = Keychain(service: "com.salsaeventtracker.ios")
    private let baseURL: URL
    private let anonKey: String

    init(baseURL: URL = SupabaseConfig.url, anonKey: String = SupabaseConfig.anonKey) {
        self.baseURL = baseURL
        self.anonKey = anonKey
        restoreSession()
    }

    func signIn(email: String, password: String) async throws {
        let url = baseURL.appending(path: "/auth/v1/token")
            .appending(queryItems: [URLQueryItem(name: "grant_type", value: "password")])
        var req = URLRequest(url: url)
        req.httpMethod = "POST"
        req.setValue(anonKey, forHTTPHeaderField: "apikey")
        req.setValue("application/json", forHTTPHeaderField: "Content-Type")
        req.httpBody = try JSONSerialization.data(withJSONObject: ["email": email, "password": password])

        let (data, resp) = try await URLSession.shared.data(for: req)
        guard let http = resp as? HTTPURLResponse, (200...299).contains(http.statusCode) else {
            throw NSError(domain: "AuthService", code: 401,
                          userInfo: [NSLocalizedDescriptionKey: "Invalid email or password"])
        }

        let raw = try JSONDecoder().decode(RawAuthResponse.self, from: data)
        let decoded = try decodeJWT(raw.accessToken)
        let newSession = AuthSession(
            accessToken: raw.accessToken,
            refreshToken: raw.refreshToken,
            expiresAt: Date().addingTimeInterval(Double(raw.expiresIn)),
            userId: decoded.sub,
            email: decoded.email ?? email
        )
        session = newSession
        try? keychain.set(raw.accessToken, key: "accessToken")
        try? keychain.set(raw.refreshToken, key: "refreshToken")
        try? keychain.set(String(newSession.expiresAt.timeIntervalSince1970), key: "expiresAt")
        try? keychain.set(decoded.sub, key: "userId")
        try? keychain.set(decoded.email ?? email, key: "email")
    }

    func signOut() {
        session = nil
        try? keychain.removeAll()
    }

    private func restoreSession() {
        guard
            let accessToken = try? keychain.get("accessToken"),
            let refreshToken = try? keychain.get("refreshToken"),
            let expiresAtStr = try? keychain.get("expiresAt"),
            let expiresAtTs = Double(expiresAtStr ?? ""),
            let userId = try? keychain.get("userId"),
            let email = try? keychain.get("email")
        else { return }
        let expiresAt = Date(timeIntervalSince1970: expiresAtTs)
        guard expiresAt > Date() else { try? keychain.removeAll(); return }
        session = AuthSession(accessToken: accessToken, refreshToken: refreshToken,
                              expiresAt: expiresAt, userId: userId ?? "", email: email ?? "")
    }

    // Minimal JWT decode (base64url payload only — no signature verification needed,
    // Supabase enforces validity server-side)
    private func decodeJWT(_ token: String) throws -> JWTPayload {
        let parts = token.split(separator: ".")
        guard parts.count == 3 else { throw URLError(.badServerResponse) }
        var base64 = String(parts[1])
            .replacingOccurrences(of: "-", with: "+")
            .replacingOccurrences(of: "_", with: "/")
        while base64.count % 4 != 0 { base64 += "=" }
        guard let data = Data(base64Encoded: base64) else { throw URLError(.badServerResponse) }
        return try JSONDecoder().decode(JWTPayload.self, from: data)
    }

    private struct RawAuthResponse: Decodable {
        let accessToken: String
        let refreshToken: String
        let expiresIn: Int
        enum CodingKeys: String, CodingKey {
            case accessToken = "access_token"
            case refreshToken = "refresh_token"
            case expiresIn = "expires_in"
        }
    }

    private struct JWTPayload: Decodable {
        let sub: String
        let email: String?
    }
}
```

```swift
// ios/SalsaEventTracker/Views/Trips/TripEditorView.swift
import SwiftUI

private struct PlaceDraft: Identifiable {
    let id = UUID()
    var city = ""; var country = ""; var startDate = Date(); var endDate = Date(); var role = "stay"
}

private struct PTODraft: Identifiable {
    let id = UUID()
    var date = Date(); var amount = 1.0; var notes = ""
}

struct TripEditorView: View {
    let trip: Trip?
    @Environment(AppModel.self) private var model
    @Environment(\.dismiss) private var dismiss

    @State private var label = ""
    @State private var startDate = Date()
    @State private var endDate = Date()
    @State private var notes = ""
    @State private var places: [PlaceDraft] = []
    @State private var ptoDays: [PTODraft] = []
    @State private var isSaving = false
    @State private var saveError: String?

    var body: some View {
        NavigationStack {
            Form {
                Section("Trip Details") {
                    TextField("Label", text: $label)
                    DatePicker("Start", selection: $startDate, displayedComponents: .date)
                    DatePicker("End", selection: $endDate, displayedComponents: .date)
                    TextField("Notes", text: $notes, axis: .vertical).lineLimit(3, reservesSpace: true)
                }
                Section {
                    ForEach($places) { $place in
                        TripPlaceRow(city: $place.city, country: $place.country,
                                     startDate: $place.startDate, endDate: $place.endDate,
                                     role: $place.role, onRemove: { places.removeAll { $0.id == place.id } })
                    }
                    Button { places.append(PlaceDraft()) } label: {
                        Label("Add Place", systemImage: "plus.circle")
                    }
                } header: { Text("Places") }
                Section {
                    ForEach($ptoDays) { $pto in
                        PTODayRow(date: $pto.date, amount: $pto.amount, notes: $pto.notes,
                                  onRemove: { ptoDays.removeAll { $0.id == pto.id } })
                    }
                    Button { ptoDays.append(PTODraft()) } label: {
                        Label("Add PTO Day", systemImage: "plus.circle")
                    }
                } header: { Text("PTO Days") }
                if let err = saveError {
                    Section { Text(err).foregroundStyle(.red) }
                }
            }
            .navigationTitle(trip == nil ? "New Trip" : "Edit Trip")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) { Button("Cancel") { dismiss() } }
                ToolbarItem(placement: .confirmationAction) {
                    Button(isSaving ? "Saving…" : "Save") {
                        Task { await save() }
                    }.disabled(label.isEmpty || isSaving)
                }
            }
        }
        .onAppear { populateFromTrip() }
    }

    private func populateFromTrip() {
        guard let t = trip else { return }
        label = t.label
        startDate = DateUtils.date(from: t.startDate) ?? Date()
        endDate = DateUtils.date(from: t.endDate) ?? Date()
        notes = t.notes ?? ""
        places = t.places.sorted { $0.sequence < $1.sequence }.map {
            var d = PlaceDraft()
            d.city = $0.city; d.country = $0.country
            d.startDate = DateUtils.date(from: $0.startDate) ?? Date()
            d.endDate = DateUtils.date(from: $0.endDate) ?? Date()
            d.role = $0.travelRole
            return d
        }
        ptoDays = t.ptoDays.map {
            var d = PTODraft()
            d.date = DateUtils.date(from: $0.ptoDate) ?? Date()
            d.amount = $0.amount
            d.notes = $0.notes ?? ""
            return d
        }
    }

    private func save() async {
        guard let token = model.authService.session?.accessToken,
              let userId = model.authService.session?.userId,
              let email = model.authService.session?.email else { return }
        isSaving = true
        saveError = nil
        let svc = SupabaseService()
        let tripBody: [String: Any] = [
            "owner_id": userId, "owner_email": email, "label": label,
            "start_date": DateUtils.string(from: startDate),
            "end_date": DateUtils.string(from: endDate),
            "notes": notes, "access_level": "owner"
        ]
        do {
            let savedTrip: Trip
            if let existing = trip {
                try await svc.updateTrip(id: existing.id, body: tripBody, token: token)
                savedTrip = existing
            } else {
                savedTrip = try await svc.createTrip(tripBody, token: token)
            }
            let placeBodies: [[String: Any]] = places.enumerated().map { idx, p in
                ["trip_id": savedTrip.id, "owner_id": userId, "owner_email": email,
                 "city": p.city, "country": p.country,
                 "start_date": DateUtils.string(from: p.startDate),
                 "end_date": DateUtils.string(from: p.endDate),
                 "travel_role": p.role, "sequence": idx, "access_level": "owner"]
            }
            let ptoBodies: [[String: Any]] = ptoDays.map { p in
                ["trip_id": savedTrip.id, "owner_id": userId, "owner_email": email,
                 "pto_date": DateUtils.string(from: p.date), "amount": p.amount,
                 "notes": p.notes, "access_level": "owner"]
            }
            try await svc.replaceTripPlaces(tripId: savedTrip.id, places: placeBodies, token: token)
            try await svc.replacePTODays(tripId: savedTrip.id, ptoDays: ptoBodies, token: token)
            await model.loadPrivateData()
            dismiss()
        } catch {
            saveError = error.localizedDescription
        }
        isSaving = false
    }
}
```

## Product Decisions

Stable decisions that should not be re-litigated without discussion.

| Decision | Rationale |
|---|---|
| No third-party Supabase Swift SDK | The REST API is simple; URLSession + JSONDecoder keeps the dependency graph small and avoids SDK version churn |
| `@Observable` throughout (no `ObservableObject`) | iOS 17+ target; `@Observable` gives per-property tracking — no whole-model re-renders on any state change |
| No SwiftData / CoreData | All data is fetched fresh on launch from Supabase; caching adds complexity with no meaningful benefit for a personal-use app |
| `KeychainAccess` for token storage | System Keychain is the only acceptable storage for auth tokens; `KeychainAccess` is a stable minimal wrapper |
| No sign-up flow in the app | The app is personal/owner-only; signups are disabled in the Supabase dashboard (Layer 1 security) |
| Tab bar with 5 tabs mirrors web | Maintains mental model parity; no reason to restructure navigation for native |
| Trips/Reviews auth-gated via `ContentUnavailableView` | Clear, native, zero-engineering sign-in prompt that uses iOS system wording |

> The living version of this document lives at `ios/docs/product-decisions.md`. Update it there when new decisions are made.

## Feature Backlog

Post-MVP ideas. **Do not build these during the initial implementation.** Add them to `ios/docs/feature-backlog.md` for future planning.

**Legend:**
- ✅ In app — implemented in this plan
- 📋 Backlog — viable, no significant obstacle
- 🚧 Obstacle — viable but requires design work or new infrastructure

---

### Token auto-refresh
**Status: 🚧 Known limitation**
Access tokens expire after 1 hour. The current plan signs the user out on 401 (see Open Issue 3). Seamless refresh requires `POST /auth/v1/token?grant_type=refresh_token` in `AuthService.refreshSession()` and a retry loop in `AppModel.loadPrivateData()`.

---

### Push notifications for event reminders
**Status: 📋 Backlog**
Use `UNUserNotificationCenter` for local notifications (no server required). User could set a reminder N days before an event's `startDate`. Store notification IDs in `UserDefaults` keyed by edition ID so they can be cancelled on trip delete.

---

### Watchlist / saved events
**Status: 📋 Backlog**
The `Event.watchlist` field already exists in the data model. Add a toggle on `EventDetailSheet` that writes `PATCH /rest/v1/events?id=eq.\(id)` with `{ "watchlist": true }`. Add a filter chip in `EventListView` to show only watchlisted events.

---

### iCal / calendar export
**Status: 📋 Backlog**
Generate an `.ics` file from an `EventEdition` and share via `UIActivityViewController`. iOS can import it directly to Calendar.app. No backend change needed — pure client-side generation using `EventKit` or a raw ICS string formatter.

---

### Widget: upcoming events
**Status: 📋 Backlog**
A `WidgetKit` small/medium widget showing the next 1–3 upcoming events from the public Supabase data. Because it reads only public data (no auth), it can use an anon-key REST call directly — no shared container or App Group needed. Add as a separate Xcode target `SalsaEventTrackerWidget`.

---

### Schengen projection / safe-date calculator
**Status: 📋 Backlog**
Given current and planned trips, calculate the earliest date the user can re-enter the Schengen area without exceeding 90 days in a 180-day window. `SchengenCalculator` already computes days-used at a check date; add a binary search over future dates to find the first "safe" re-entry date.

---

### Offline mode / data cache
**Status: 🚧 Obstacle**
The app fetches fresh on every launch. A read-through cache of public event data (SQLite via `GRDB` or `NSPersistentStore`) would make the event list available without a network connection. Auth-gated data (trips/reviews) should not be cached on disk. Design decision needed: cache TTL, invalidation strategy.

---

### User sharing (attendance / reviews)
**Status: 🚧 Infrastructure gap**
The web app's `USER_SHARING_PLAN.md` documents a scope-based permission system (`attendance.read`, `reviews.read`, `trips.read`). This is a backend-first feature — requires `user_permissions` table, `has_permission()` RLS function, and `shared_event_attendance` table. The iOS app would then load attendance data from `shared_event_attendance` instead of `personal_trip_places` for non-owner sessions. See `USER_SHARING_PLAN.md` for the full migration plan.

## Open Issues

### Issue 1: Dead filter state in EventListView (gap)

`AppModel` declares `filterYear`, `filterMonth`, `filterCountry`, and `filterSize` and the `EventListView` filter closure reads them, but no UI component ever sets them — they are permanently `""`. The web app has year/country/size filters. Options:

- Add a filter panel to `EventListView` (e.g., a `.sheet` or expandable toolbar section) that exposes pickers for each field.
- Or remove the four dead state properties from `AppModel` and simplify the filter closure to only sort + historical toggle, documenting that per-field filtering is a follow-up task.

### Issue 2: Shared search query across tabs (design decision)

Both `EventListView` and `FestivalListView` bind to `model.searchQuery`. A search typed in the Events tab persists when the user switches to the Festivals tab and vice versa. Decide whether this is intentional (a single app-wide search bar, like a global filter) or a bug. If per-tab search is desired, replace the single `searchQuery: String` with:

```swift
var eventSearchQuery: String = ""
var festivalSearchQuery: String = ""
```

and update each view's `@searchable` binding accordingly.

Access tokens expire after 1 hour. The current plan signs the user out on 401 (via `SupabaseService.AuthError.tokenExpired` → `AppModel.loadPrivateData` catch → `signOut()`). If seamless background refresh is needed later, add:

```swift
}
```

Then in `AppModel.loadPrivateData`, retry once after a successful refresh before giving up and signing out.
